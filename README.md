# Interliving — website concept

Live: https://mohammedbagowabair.github.io/Interliving-Website/ (Bahasa Melayu: `?lang=ms`)

Vite + React + TypeScript + Tailwind. English by default with a Bahasa Melayu toggle; enquiries open WhatsApp with a prefilled message in the current language.

- Business facts come from public listings (Google Maps and booking/review sites). Unknowns are left out.
- Street/building photos: Wikimedia Commons, credited on the page. Interior photos are illustrative stock (Unsplash) and labelled as such.
- Map: © OpenStreetMap contributors.

```
npm install
BASE_PATH=/Interliving-Website/ npm run build
npx gh-pages -d dist
```

Concept prepared for the business; not an official site.
